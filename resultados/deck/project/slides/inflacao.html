Etapa 03 · O indicador

Média de porcentagens não é uma taxa

Métrica descartada

2,18%

Média simples das razões por pedido. Dá o mesmo peso a um pedido de 2 e a um de 19 itens.

Taxa correta

1,55%

Soma dos itens faltantes dividida pela soma dos itens transportados.

Diferença

1,40×

A métrica descartada inflava o problema e sustentava uma urgência que os dados não têm.

É a diferença entre "média das porcentagens" e "porcentagem do total". Só a segunda é uma taxa operacional.
